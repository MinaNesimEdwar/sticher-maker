# صانع استيكرات حتة

أداة بتشتغل في المتصفح على جهازك: بتشيل خلفية الصورة، وتعمل حواليها إطار زي الاستيكر، وتنزّلها PNG شفافة بجودة الطباعة.

مبنية بـ React و Vite.

## التشغيل على جهازك

دبل كليك على `start.bat`. أول مرة بيسطّب المكتبات (دقيقة تقريباً)، وبعدين بيفتح الأداة في المتصفح. سيب الشاشة السودا مفتوحة طول ما انت شغال.

أو من التيرمنال:

```
npm install
npm run dev
```

## الرفع على Vercel

Vercel بيتعرّف على المشروع لوحده إنه Vite، ومحتاجش أي إعدادات.

- **عن طريق GitHub:** ارفع الفولدر ده على repo، وبعدين في Vercel دوس Add New → Project واختار الـ repo، ودوس Deploy. أي تعديل هترفعه على GitHub بعد كده هيتنشر لوحده.
- **من التيرمنال:** `npx vercel` جوه الفولدر ده، وسجّل دخول لما يطلب منك.

الإعدادات لو احتجتها: Build Command `npm run build`، و Output Directory `dist`.

## هيكل المشروع

- `src/App.jsx`: الواجهة كلها.
- `src/lib/sticker.js`: إزالة اللون السادة وبناء الإطار والظل وخط القص.
- `src/lib/exporter.js`: الذكاء الاصطناعي، وحفظ PNG/WebP، والحفظ في فولدر أو ZIP.
- `src/styles.css`: الشكل.

## الطرق الثلاثة لإزالة الخلفية

| الطريقة | امتى تستخدمها |
| --- | --- |
| ذكاء اصطناعي | صور حقيقية أو رسومات معقدة. أول مرة بينزّل موديل حوالي ٨٠ ميجا ومحتاج نت، وبعد كده بيتحفظ في المتصفح. |
| لون سادة | تصميم على خلفية بيضا أو لون واحد. سريع ومن غير نت. علّي "دقة إزالة اللون" لو فضل جزء من الخلفية، وقلّلها لو الشكل نفسه اتاكل. |
| شفافة أصلاً | ملفات PNG شفافة جاهزة، بيضيف الإطار بس. |

## الإعدادات

- **السُمك:** نسبة من أطول ضلع في الصورة، فالشكل بيفضل ثابت مهما غيرت مقاس التنزيل.
- **نعومة الحواف:** بتدوّر الزوايا الداخلية عشان القص يبقى أسهل وأنضف.
- **اقفل الفراغات اللي جوه الشكل:** بيملا الفتحات اللي جوه (زي ما بين الإيد والجسم) بلون الإطار، زي الاستيكر الحقيقي.
- **صيغة الملف:** PNG أو WebP أو الاتنين. WebP أخف وللموقع، وPNG للطباعة والأوردرات. زرار "نزّل الكل ZIP" بينزّل كل الصور في ملف واحد، ولو اخترت الاتنين بيقسمهم جواه في فولدرين `webp/` و`png/`. فك الملف بـ Extract All قبل ما تستخدم الصور. خط القص دايماً PNG.
- **الظل:** للمعاينة وصور البوستات. لملف الطباعة اختار "من غير".
- **خط القص:** زرار "نزّل خط القص" بيطلع PNG فيه خط أسود على حدود الاستيكر بالظبط، بنفس المقاس، عشان ماكينة القص أو المطبعة.

## خصوصية

حتى وهي على Vercel، الصور مش بتترفع لأي سيرفر. كل المعالجة بتحصل في متصفح اللي بيستخدم الأداة. Vercel بيبعت ملفات الأداة نفسها بس.

## ترخيص

إزالة الخلفية بالذكاء الاصطناعي بتستخدم مكتبة `@imgly/background-removal` (ترخيص AGPL-3.0). استخدامها جوه الفريق على أجهزتكم مفيهوش مشكلة. رابط Vercel أي حد معاه يقدر يفتحه، فلو الأداة هتبقى متاحة للناس بره الفريق، راجعوا شروط الترخيص الأول (AGPL بيطلب إن كود الأداة يبقى متاح لأي حد بيستخدمها). لو هي للفريق بس، فعّلوا Deployment Protection من إعدادات المشروع على Vercel عشان محدش غيركم يفتحها.
